# Decisions (ADRs)

One short file per decision. Numbered, never edited after the fact: to change one, write a new ADR that says "Supersedes 000X".

Template:

```md
# 000X: Title

Status: Accepted | Superseded by 000Y
Date: YYYY-MM-DD

## Decision
One or two sentences.

## Why
The reason, in plain words.

## Consequences
What this makes easier or harder.
```
