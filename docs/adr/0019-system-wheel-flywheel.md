# 0019: System wheel opens a flywheel of apps and agents

Status: Accepted
Date: 2026-11-13
Supersedes the System wheel row of 0007. The rest of 0007 stands.

## Decision
Turning the system wheel no longer switches function on each notch. The first notch opens a flywheel in the top-left corner of the screen. It holds Home, then every app and Task agent in the same order as the Home comb. Five sit on an arc around the corner, and the middle one is selected.

| Control | Flywheel |
| --- | --- |
| System wheel / D-pad up and down | Turn it. It never ends. |
| A or push bar | Open the selected app, or the selected Task agent's screen. |
| B | Close it and stay where you were. |
| Nothing for 2 seconds | It hides by itself. |
| Mic | Closes it and talks as usual. |

It opens on what is on screen now. Behind it, a progressive blur is strongest in the corner and fades toward the middle of the screen. Docked, it holds the companion functions (Dock, Agents, Focus, To-Do).

## Why
With apps and Task agents together there are too many to step through blindly, and switching on every notch opened every app on the way. Picking first and opening on purpose is calmer. Keeping Home's order means the user learns one layout.

## Consequences
Getting to another app takes one extra press (A). Task agents can be reached from anywhere without going Home first.
