# 0002: Simulate the hardware, show it with renders

Status: Accepted
Date: 2026-11-12

## Decision
No physical hardware this weekend. The device is a full-screen web app; the physical form is shown with Blender renders.

## Why
We own no boards, parts shipping is too slow, and hardware bugs kill hackathon demos.

## Consequences
We must never call the web app real hardware. Pitch framing: "software-first, hardware-ready".
