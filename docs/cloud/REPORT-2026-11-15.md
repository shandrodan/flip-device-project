Fixes found along the way (in those commits):

- **Engine leak (item 1).** The server started OpenCode through the `node_modules/.bin` shell shim. Killing it left the real `opencode.exe` running, so every model or key change leaked an engine (one was still running from the baseline). The server now starts the binary directly.
- **Build commands broken under `pnpm dev` (item 5).** `pnpm run` exports its own config as `npm_config_*` variables. Here a user `~/.npmrc` line (`allow-scripts=…`) became `npm_config_allow_scripts`, and npm 11 then refused every project install ("EALLOWSCRIPTS"). Build commands, the dev server and OpenCode now start without the server's `npm_*` variables. Under systemd this never happened. It's worth knowing for local development.
- **Vite serves syntax errors as HTTP 200 (item 4).** It only scans imports, so the error check also loads the page in the browser.
- **The Device snapshot carries only the newest 80 Notes (item 6).** Tests and agents can't count Notes from it. Search goes to the server.
