# renders

Blender work. Form and render list: see `docs/SHAPE.md`.

- `scripts/`: bpy scripts (AI-generated, run in Blender's scripting tab)
- `out/`: exported PNGs and videos used in the pitch
- `studio/`: stills and takes from studio mode (`docs/STUDIO.md`). Not in git: scenarios make them again.

Quality comes from lighting, materials and a slow camera move, not model detail.
